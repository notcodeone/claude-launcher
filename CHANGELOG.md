# История версий

Номер версии — в `pubspec.yaml`, как выпускать новую — в README («Версии»).
Раздел версии отсюда становится текстом её выпуска на GitHub.

## 1.5.8 — 2026-10-02

### Исправлено

- Windows: обновление Claude запускает установку напрямую через Windows — без окна, а
  попытку с правами администратора — через стандартный запрос Windows. Раньше PowerShell
  мог не запуститься вовсе, и обновление падало с «нет ответа».
- Путь к журналу установки Claude — отдельной строкой в «Обновлениях»; по нажатию
  журнал открывается.
- Windows: «Обновить до …» у ClaudeLauncher могло открыть страницу на GitHub вместо
  обновления. Установка теперь узнаётся по деинсталлятору в папке программы, а если
  установщика в сведениях о выпуске нет — лаунчер спрашивает GitHub ещё раз. Если
  обновиться самому всё же нельзя, в карточке написано почему; переносная версия
  предлагает «Скачать».

## 1.5.1 — 2026-10-01

### Новое

- Kill Switch (раздел «Эксперименты») — для тех, кто открывает Claude через VPN. Весь
  трафик Claude — приложения, его Claude Code и машины Cowork — идёт через прокси
  лаунчера на `127.0.0.1`. Сменилась сеть — соединения с Anthropic рвутся мгновенно, а
  новые ждут, пока лаунчер проверит страну: та же — работа продолжается, другая или
  Claude там недоступен — соединения получают отказ, а Claude закрывается. Если прокси
  недоступен, Claude остаётся без сети, а не идёт в обход.
- Кнопка Kill Switch в шапке — пока он включён. Точка на ней — состояние, в её окне —
  проверена ли сеть, в какой стране выпускается трафик, когда Kill Switch сработал, и
  «Проверить сеть». Ход проверки виден в шапке.
- Пока Kill Switch включён, обновления Claude ставит лаунчер: встроенное обновление Claude
  ходит мимо прокси, поэтому оно выключено. Лаунчер сам узнаёт о новой версии — только
  через проверенную сеть, — проверяет архив и подпись, закрывает Claude, ставит
  обновление и открывает Claude снова.
- После выхода из лаунчера, пока Claude открыт, защиту держит фоновый процесс без окна и
  значка; Claude закрылся — он убирает настройку и завершается. Kill Switch выключили при
  открытом Claude — его трафик идёт через лаунчер без проверок, пока Claude не закроют.
- По желанию — закрывать Claude при любой смене сети, не дожидаясь проверки страны.
- Описания разделов настроек; «Скрывать значок Claude» — теперь в разделе «Claude Code».

## 1.4.1 — 2026-10-01

- macOS: после выходов из лаунчера в фоне больше не копятся процессы, которые ждут
  закрытия Claude, — запущенный лаунчер их убирает.

## 1.4.0 — 2026-10-01

### Новое

- Настройки — страницы внутри окна вместо диалога: список разделов «Основные»,
  «Claude Code», «Обновления» и «Эксперименты», в каждом — свои карточки. Переход —
  плавный: страницы сдвигаются по общей оси, значок и название раздела перелетают из
  списка в заголовок, карточки поднимаются по очереди. Назад — стрелкой в шапке или
  Esc, открыть — шестерёнкой или ⌘, (Ctrl+, на Windows).
- В разделах видно состояние: страна и доступен ли Claude, подключены ли события Claude
  Code, версия и проверка обновлений с кнопками «Проверить сейчас» и «Что нового».
- Тема окна — в «Основных», переключателем из трёх вариантов; кнопка темы из шапки
  убрана.
- У каждого эксперимента — свой переключатель; лимиты профиля включаются отдельно.
  Если экспериментальные функции были включены, лимиты останутся включёнными.

## 1.3.1 — 2026-10-01

### Исправлено

- Windows: обновление из лаунчера не срывается из-за процесса, который возвращает
  Claude уведомления, — при обновлении он не запускается, новая версия забирает

  через 2, — чтобы не обрывать его, если он выходит штатно, но не мгновенно.

- README: подробные шаги удаления на macOS.

## 1.3.0 — 2026-10-01

### Новое

- Обновления из самого лаунчера: когда выходит новая версия, в подвале окна и в меню

## 1.2.2 — 2026-10-01

### Новое

- Настройка «Экспериментальные функции»: показывает функции, которые ещё проверяются.
  Лимиты профиля теперь среди них и по умолчанию скрыты.

  время сброса. «Проверить снова» перечитывает данные, не закрывая окно.

## 1.1.0 — 2026-09-30

### Новое

- Уведомления Claude Code приходят от ClaudeLauncher, пока он запущен: о запросе
  разрешения, вопросе и готовой задаче. Сам Claude в это время их не показывает, а после
  выхода из лаунчера снова уведомляет сам. Нажатие открывает сессию в Claude.
  Выключается в настройках.
- Проверка страны перед запуском профиля: где Claude недоступен, профили не запускаются,
  а в окне — предупреждение. Страна с флагом — в меню кнопки с меткой в шапке.
- Окно лаунчера открывается при запуске и показывает, как проверяется страна и
  открывается профиль по умолчанию.
- Новая иконка — «искра» Claude и «играть»: в приложении, строке меню macOS, трее
  Windows (чёрная для светлой панели задач, белая для тёмной), уведомлениях,
  установщиках и шапке окна.
- Окно установки в DMG: фон, крупные значки и стрелка к «Программам».
- Версия приложения — в подвале окна.

### Исправлено

- Время и токены задачи больше не сбрасываются от сообщений посреди работы: своих
  дописок, отчётов фоновых агентов, уведомлений фоновых задач.
- Токены считаются как в Claude Code — вместе со скрытыми рассуждениями модели: раньше
  лаунчер показывал примерно втрое меньше. Новое значение набегает плавно, а не
  перескакивает.
- Вопрос с вариантами ответа на карточке — «нужен ответ», а не «нужно разрешение».
- Приложение можно обновить, даже если после выхода лаунчер ждёт закрытия Claude,
  чтобы вернуть ему уведомления.
- README: как открыть неподписанное приложение на macOS 15 и новее.

## 1.0.0 — 2026-09-29

Первая версия.

- Профили Claude — у каждого свой вход в аккаунт. Переключение в один клик из строки
  меню, трея или окна, одновременно открыт один профиль.
- Профиль по умолчанию открывается при запуске лаунчера.
- Сессии Claude Code на карточке профиля: работает, ожидает, готово — со временем и
  токенами. Нажатие на название открывает сессию в Claude.
- Значок самого Claude в строке меню или трее можно спрятать.
- Установщики: DMG для macOS, Inno Setup и переносная версия для Windows.
