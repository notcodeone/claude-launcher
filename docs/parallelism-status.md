# Состояние тестовой ветки parallelism

2 октября 2026. База: `72bb1c6`. Версия: `1.5.10-parallelism.1+23`.

## Сделано

- Экспериментальный параллельный запуск, показ и адресное закрытие профиля.
- Защита от пересекающихся запусков и неоднозначных переходов.
- Уведомления с исходным профилем; неизвестные события Code не присваиваются
  оставшемуся аккаунту после закрытия соседнего.
- Восстановление нескольких профилей после обновления Claude.
- Корректный статус необходимости перезапуска каждого профиля для Kill Switch.
- Защита тестовой сборки от стабильного канала обновлений, включая macOS-версию
  `1.5.10.1`, в которую Flutter преобразует предварительный номер.
- [Исследование полной поддержки](parallel-profiles.md) и воспроизводимый
  `tool/parallel_smoke_macos.py`.

## Проверено

- `flutter analyze --no-pub`: без замечаний.
- Полный набор: **200 тестов прошли**. После последних уточнений отдельно прошли
  8 тестов событий/уведомлений и 4 теста обновлятора, включая новый регрессионный.
- Живой тест Claude 2.19675.0 на macOS: два временных профиля работают одновременно;
  закрытие одного не затрагивает другой и ранее открытые процессы. Тестовые
  процессы закрыты, временные каталоги удалены.
- Повторный низкоуровневый запуск той же папки создаёт дубликат — дедупликация
  со стороны Claude **не подтверждена, наблюдалось обратное**. Лаунчер использует
  показ по PID и свою блокировку операций.
- Release-сборка macOS: успешно, universal binary **arm64 + x86_64**.

Размер: около 21 МБ. `hdiutil verify` — VALID; `codesign --verify --deep --strict`
для приложения непосредственно внутри смонтированного DMG — успешно (ad-hoc).
SHA-256: `611c4afd452ea4a04f221e590ebd58332ae6d967407cda41a383fca30e3e6beb`.

Включение: Настройки → Эксперименты → Параллельные профили — тест.
Сборка использует существующие настройки и профили лаунчера. Основное приложение
в `/Applications` автоматически не заменяется; устанавливается пользователем.

## Осталось до полноценной поддержки

1. Адресный возврат входа из браузера и доставка URL конкретному PID/профилю.
2. Достоверная привязка новых Code-сессий; восстановление реестра после перезапуска.
3. Авторизованные испытания двух аккаунтов, двух Cowork-задач и общих интеграций.
4. Полная Windows/MSIX-матрица, включая активацию окна и общую VM-службу.
5. Аудит фактического сетевого трафика всех экземпляров и VM, внешних запусков,
   передачи охраннику, изменения порта и аварийного восстановления.
6. Общая транзакция обновления Claude с блокировкой запусков и восстановлением
   при ошибке; набор профилей для автозапуска, глобальные горячие клавиши и Dock.

Вход проверять при единственном открытом профиле. В тестовом параллельном режиме
новые Code-сессии не появляются автоматически на карточках; общие уведомления
сохраняются. При нескольких экземплярах переходы к сессиям из лаунчера заблокированы.
Cowork не объявлен совместимым. Подробная матрица и критерии приёмки — в исследовании.
