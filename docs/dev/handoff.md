### Проверка на Windows (для товарища, после выпуска 1.5.10)

```
Поставить: irm https://raw.githubusercontent.com/notcodeone/claude-launcher/main/tool/install.ps1 | iex
   Должно быть: «Готово: ClaudeLauncher v1.5.10 установлен» (сумма файла проверяется по пути).

1. Открой профиль, начни сессию в Claude (вкладка Code), подожди ответа.
   Переключись на другой профиль в лаунчере.
   Должно быть: Claude закрывается сам за несколько секунд, без вопроса «закрыть принудительно».
   Вернись на первый профиль — сессия на месте.
2. Сразу после запуска профиля (в первые 5–10 секунд) переключись на другой.
   Должно быть: лаунчер чуть подождёт, пока Claude загрузится, и закроет его так же.
3. Пришли файл main.log Claude: %LOCALAPPDATA%\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Local\Claude\logs\main.log
   или (если его нет) поищи main.log в %LOCALAPPDATA%\Claude\logs и %APPDATA%\Claude\logs.
   Нужно: строки «boot: done» и «session ending … quitting the app».
4. Настройки → Kill Switch включён, «Cowork — только через Kill Switch» включено.
   Открой Cowork и дай ему задачу с выходом в интернет.
   Должно быть: Cowork работает (ходит через Kill Switch). Выключи VPN — Cowork теряет сеть.
5. Включи «Скрыть значок Claude», перезапусти Claude из лаунчера.
   Должно быть: значка Claude в трее нет.
6. С открытым лаунчером выйди из сеанса Windows (Выход) и войди снова.
   Должно быть: уведомления Claude снова приходят от самого Claude, когда лаунчер не запущен.
```
